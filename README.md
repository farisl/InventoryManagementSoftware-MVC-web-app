# Inventory Management Web Application

A full-featured ASP.NET Core MVC application for managing product inventory across multiple users and roles.

### 🛠️ Tech Stack
- ASP.NET Core MVC (C#)
- Entity Framework Core (Code-First, SQL Server)
- SignalR for real-time notifications

### ⚙️ Key Features
- User authentication and role-based authorization
- Product management with search and filtering by name/date
- Real-time stock updates via SignalR
- Layered architecture for better scalability and maintenance

### 🚀 Notes
The application runs independently (no external API required).
